# PokéCorner

Питомец-покемон для рабочего стола Windows. Живёт в углу экрана поверх окон и растёт от
того, что ты просто работаешь за компьютером: мышь, клавиатура и геймпад копят очки ухода,
лакомства и монеты, а за активность встречаются новые покемоны.

## Возможности

- Анимированный питомец (спрайты Gen V) поверх обычных окон и под панелью задач. Реагирует
  на клик, кормление и эволюцию, кричит голосом своего вида.
- Поимка: заполнилась шкала активности — встретился покемон; до 3 встреч копятся.
- Коллекция и Pokédex всех поколений 1–5: фильтры, поиск, сортировка, прозвища, избранное,
  выбор отображаемой стадии эволюции.
- Эволюция по накопленным очкам ухода — кнопкой, когда питомец готов.
- Магазин: лакомства, бустер роста, талисман удачи (×4 к шансу шайни), яйца четырёх редкостей
  с часовой инкубацией.
- Режимы ухода: Chill, Hardcore (обиженный питомец убегает) и Супер-хардкор.
- Прячется, когда на его мониторе игра или видео во весь экран.
- Работает без интернета: каталог видов, спрайты и крики поставляются с установщиком.

## Установка

Скачай `PokeCorner-Setup.msi` со страницы **Releases** и запусти. Установщик кладёт приложение
в `C:\Program Files\PokeCorner` и создаёт ярлык в меню «Пуск». Установщик не подписан, поэтому
Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

Обновление — просто установить новую версию поверх: прогресс хранится отдельно и не теряется.

## Где лежат данные

| Что | Где |
|---|---|
| Сохранение (коллекция, монеты, настройки) | `%APPDATA%\PokeCorner\state.json` |
| Диагностика «питомец под окнами» | `%APPDATA%\PokeCorner\zorder.log` |
| Спрайты, крики, каталог видов | `C:\Program Files\PokeCorner\Data\` |

## Сборка из исходников

Нужны .NET 8 SDK и Windows.

```
dotnet build PokeCorner.sln
dotnet test PokeCorner.sln
```

Установщик собирается WiX 5 — подробности и разовая подготовка в
[installer/README.md](installer/README.md):

```
dotnet publish src/PokeCorner.App/PokeCorner.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=none -o publish/
dotnet build installer/PokeCorner.Installer.wixproj -c Release
```

## Структура

| Путь | Что там |
|---|---|
| `src/PokeCorner.Core` | Доменная логика без UI: поимка, эволюция, уход, магазин, сохранение, клиент PokeAPI |
| `src/PokeCorner.App` | WPF-оболочка: оверлей питомца, меню, трей, хуки ввода |
| `tests/` | xUnit-тесты обоих проектов |
| `installer/` | WiX-проект MSI |
| `docs/` | Спеки, планы разработки, чеклист ручной проверки |
