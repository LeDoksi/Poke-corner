# PokéCorner — точка входа для Claude

Питомец-покемон для рабочего стола Windows (.NET 8, WPF). Цель — довести существующее приложение до релиза для владельца (Georgy) и пары друзей, а не переписывать его.

## Правила работы

- Отвечай Georgy по-русски, коротко и по делу. Продукт, ощущения и приоритеты решает он; от Claude нужны анализ, варианты и рекомендация.
- Прошлые решения считай гипотезами и проверяй их на логику, удобство и длину пользовательского пути. Лишние экраны и системный шум убирай. Хорошие решения сохраняй.
- Для существенного выбора давай 2–3 варианта с плюсами, минусами и рекомендацией. Вопросы собирай пачкой. То, что не блокирует работу, записывай в DECISION LOG и продолжай.
- Согласованные функции не удаляй без явного одобрения Georgy.
- Дизайн, код, проверки и канбан делает Claude. Астра (ChatGPT) только генерирует растровые картинки по промптам Claude, а Claude их принимает и встраивает.
- Не заявляй, что тесты прошли, если ты их не запускал. WPF собирается и тестируется только на Windows, то есть на ПК Georgy через Remote Control.

## Код и сборка

- `src/PokeCorner.Core` — домен без UI: экспедиции, питомник, магазин, сохранения. Каждое изменение проходит через `AppState.CommitAsync`.
- `src/PokeCorner.App` — WPF: оверлей, меню (`Popup/`), трей, онбординг. Тема Night Diary — `Theme/NightDiary.xaml`. Старая `PokedexTheme.xaml` уходит по мере переноса экранов.
- Рантайм-данные сейчас копируются в сборку из `docs/design-v2/...` через `src/PokeCorner.App/RuntimePackage.props`. Не перемещай и не удаляй файлы в docs/design-v2, пока они не перенесены в src.
- Рабочая ветка — `codex/night-diary-pilot`. `main` обновляется только на релизе.
- Сборка и тесты: `dotnet build PokeCorner.sln`, `dotnet test PokeCorner.sln` (только Windows).
- Не коммить скриншоты-доказательства и временные превью: репозиторий и так весит больше 1,5 ГБ.
