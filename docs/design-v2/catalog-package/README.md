# Полный каталог PokeAPI и подготовленные BW-ресурсы

Подготовленный пакет для следующей реализации; не подключён к текущей игре. catalog.json содержит все 1025 основных видов независимо от наличия анимаций. assets/normal и assets/shiny содержат проверенные GIF (868 и 865). Голосов в пакете нет.

В source/ сохранены исходные таблицы PokeAPI с типами, параметрами видов, именами, описаниями и правилами эволюции. Языки и версии описаний сохраняются в исходном виде; готовая русская локализация всех записей не обещана. source URL, ревизия и хеши записаны в catalog.json. Собственные редкости, рецепты питомника, ягодные цены и особенности не следует принимать из канонических игровых правил автоматически.

Воспроизводимое получение — ../prepare-catalog-package.py. Для повторной подготовки BW-файлов нужен временный кэш ../catalog-frame-audit.py. Первая проверка была выполнена по закреплённой версии спрайтов. Обычная и shiny-доступность записаны отдельно, пригодность голоса не подтверждена. Не устанавливать этот пакет вместо существующего catalog.json приложения: форматы различаются.
