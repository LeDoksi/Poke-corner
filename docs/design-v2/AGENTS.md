# Питомник: только первое звено эволюционной семьи

Во всех рецептах и примерах потомство — начальный вид полной эволюционной цепочки, включая baby-вид. Уровень 1 не делает развитый вид начальным. Для одинаковых родителей также использовать начальный вид их семьи. Проверять каталог как достижимость «вылупление + эволюции», а не требовать прямой рецепт для каждой развитой формы. Для легендарной семьи уникален рецепт начального вида; последующие виды не добавлять в яйца ради покрытия.

## Incorrect

```text
Raichu + Raichu -> Raichu уровня 1
Отдельный рецепт вылупления Venusaur для покрытия #0003
```

## Correct

```text
Raichu + Raichu -> Pichu уровня 1 -> Pikachu -> Raichu
Рецепт Bulbasaur -> Ivysaur -> Venusaur
```
