## Выбранная техническая основа

Не вводим новую БД, общий фреймворк операций, второй GIF-декодер или сетевую зависимость при запуске. Используем нынешние Core/App, JSON store, платформенный reduced-motion и существующие кэши. Схему и барьер публикации закрепляет T02; остальные механики потребляют их.

Синтетические тесты текущего кода и assert-скрипты подготовки не означают живую приёмку глобального апдейта. Настоящие saves/cache не открывались; все голоса не прослушаны, лор всех пар не принят индивидуально. needsThemeReview остаётся видимым. Полная мебель, сон, формы и одежда не входят в этот релиз. Готовность runtime фиксируется только по выполнению канбана.

## Воспроизведение проверок

Из корня проекта, все команды с rtk:

```powershell
$PokePython = 'C:/Users/Georgy/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
rtk proxy node docs/design-v2/build-nursery-draft.mjs
rtk proxy node docs/design-v2/check-nursery-roots.mjs
rtk proxy $PokePython -X utf8 docs/design-v2/final/prepare-balance.py
rtk proxy $PokePython -X utf8 docs/design-v2/catalog-package/prepare-runtime-content.py
rtk proxy $PokePython -X utf8 docs/design-v2/voice-preview/prepare-delivery.py --check
rtk proxy $PokePython -X utf8 docs/design-v2/final/build.py
rtk proxy $PokePython -X utf8 docs/design-v2/final/check-preparation.py
rtk proxy dotnet test PokeCorner.sln --no-restore --verbosity minimal
```

VSTest в ограниченной песочнице может не открыть loopback-сокет (SocketException10013); для этой проверки нужен запуск с разрешением вне ограничения. Файлы тестов синтетические, пользовательскую коллекцию они не читают.
