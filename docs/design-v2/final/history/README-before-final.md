Актуальные правила питомника — NURSERY.md. Случайный начальный вид из 2–3 результатов для разных родителей, результаты отличаются от обоих родителей. Одинаковые родители дают начальный вид своей семьи. Предмет магазина выбирает только среди начальных видов, не позволяет получить готовую эволюцию.

Статичный макет питомника: nursery.png. Сравнивает случайный результат и выбор с талисманом. Рецепт Бульбазавр + Оддиш → варианты #0069 / #0406 / #0546, группа и цена иллюстративны, не утверждены. Композиции двух панелей исследовательские; в дальнейшем информацию об особенностях и общей удаче нужно показывать в обоих режимах, а переключение талисмана не должно неожиданно менять всё расположение.
