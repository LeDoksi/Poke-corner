# Проверка смысла трофеев — 2026-10-11

Проверены изображения всех 56 активных наград: четыре ступени каждой из десяти цепочек и шестнадцать самостоятельных целей. Условия взяты из текущего ACHIEVEMENTS.md, изображения — из final-assets/manifest.json. Контактный лист исходного банка просмотрен целиком; для population проверены именно активные домики sourceId=decor, а не архивная группа Иви. Семь исключённых наград не оценивались как активные.

Это визуальная экспертная оценка связи изображения и механики, не тест распознавания пользователями. Численные проверки альфы/размещения не доказывают смысловую читаемость. Итог по 26 карточкам: **17 оставить, 6 уточнить, 3 заменить**. Условия и пороги достижений не менять ради уже нарисованной картинки.

## Порядок правок

1. Обязательные: species, population, evolved-expedition — 9 внешних видов. Для population уже есть пригодный архивный исходник, поэтому новую генерацию для него не планировать.
2. Уточнения: team, nursery, evolution, type-team, all-berries, berry-evolution — 15 внешних видов. Для all-berries использовать окончательные шесть ягод магазина.
3. После замены пересоздать цветные файлы и точные маски, проверить три позиции каждой награды и обновить превью. Канонические ID, условия и пороги оставить прежними.

**Статус:** аудит выполнен; художественные замены здесь рекомендованы, ещё не произведены. Старый технический QA не означает, что смысловая проверка всех трофеев пройдена. Текущие файлы сохранены, готовность арта к окончательной приёмке требует этих исправлений.
