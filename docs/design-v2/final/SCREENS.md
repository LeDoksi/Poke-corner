# Карта экранов и окончательные правила

`index.html` — шесть статичных листов в общей системе: уголок, магазин, достижения/полка, настройки, шесть шагов обучения и служебные состояния. Ни одна кнопка не меняет сохранение. Существующие одобренные макеты функций остаются визуальными референсами; числа и правила ниже имеют приоритет над устаревшими примерами изображений. Изображения не являются интерактивным прототипом.

| Сценарий | Визуальный референс | Что переносить в реализацию |
|---|---|---|
| Покедекс / личная карточка | `../pokedex-filters.png` | Номер, типы, семейная редкость, shiny, избранное; поиск, сортировки по номеру/дате/типу; фильтр «Есть куда расти». Характер описательный, особенности функциональные отдельно. Кличка, дата поимки, фактически достигнутая ветка; закрытые эволюции силуэтами. Вид без ассета — «Этот вид ещё никто не встречал», без силуэта; описание только если вид уже открыт. |
| Выбор экспедиции | `../expeditions-compact.png` | Восемь компактных текстовых кнопок, один пейзаж выбранной местности. Сложности 1/10/25; длительности 30/90/180/360 минут; состав 1–3, виден вклад каждого и итоговая гарантия. У двоих нет встречи/дополнительной добычи, у одного −20% базы. |
| Поход / получение | `../expedition-states.png` | Один активный поход, время идёт при закрытом приложении. Команда не меняется. Прервать с подтверждением: без добычи/XP; при фактическом завершении вместо отмены получение. Награды не сгорают, результат не перебрасывается. Старая картинка с двумя участниками и встречей — не допустимый состав для такого исхода. |
| Питомник / гнездо / вылупление | `../nursery.png`, `../nursery-states.png` | Одна совместимая пара, 2–3 заранее показанных корневых вида. Выбор случайный или талисманом, 10/14 ягод. Время 2/4/6/8 по самому редкому доступному исходу; фиксируется при запуске. Никаких готовых вторых/третьих стадий и гарантированного shiny от родителей. Яйца из магазина удалены. |
| Эволюция | `../care-evolution.png` | Вход напрямую из личной карточки, без промежуточной дублирующей карточки. Уход +6 конкретных ягод; разные ветки случайно либо выбор камнем, камень тратится только для осмысленного выбора. Показать доступные/закрытые ветки, стоимость, нехватку и пути докупки/похода. Редкость сохраняется. |
| Очередь встреч / поимка | `../encounters.png`, `../encounters-list.png` | За активность только закрытый покебол без вида/силуэта/типа. Экспедиционная встреча может показывать встреченный вид. Бросок → покачивания → открытие → результат; поимка гарантирована, добавление экземпляра однократно. Кнопка «Продолжить», не «В коллекцию» как повторная операция. Талисман расходуется и при не-shiny. |
| Реакции | `../reactions.png` | Старый набор эмоций на картинке сокращён: поглаживание лёгким увеличением + хорошие общие пиксельные сердечки + выбранный голос; кормление крошками вверх/влево/вправо от фигуры и crunch, не привязка ко рту. Клубок постоянный до внимания, ступени 3/4,5/5,75 часа в единственном режиме Chill, без наказаний. Сон и отдельная радость удалены. Никаких 1000 вручную нарисованных наборов реакций. |

## Настройки: сверка с приложением

Прочитаны текущие AppSettings, SettingsView, SettingsViewModel и код обработчиков. По решению 12 октября CareMode/SuperHardcoreEnabled больше не представлены в UI (только legacy decode); в новом макете остаются AutoHideInFullscreen, ShowProgressPanel, PetSizePixels 48–384, CrySoundVolume 0–100, StartWithWindows, повтор обучения и очистка с двумя подтверждениями. Добавляется независимый EffectsSoundVolume 0–100, default 30, для crunch и общих звуков; значение 0 отключает только эффекты. ScreenCorner, MonitorIndex и PetPositionX/Y сохранены в данных, перетаскивание остаётся способом расположения; не выдавать эти поля за существующие отдельные переключатели SettingsView.

Загрузка настроек не запускает обработчики пользовательских изменений. Размер/громкость применяются как сейчас; нет самопроизвольного звука при открытии настроек. 0% — настоящее выключение голоса. Настоящую регистрацию автозапуска сверять с Windows.

Общие эффекты следуют `SystemParameters.ClientAreaAnimation` Windows, включая смену системного значения во время работы. Собственный переключатель «Уменьшить анимации» не добавляется. При отключении движения постоянный клубок недовольства становится неподвижным; базовый GIF остаётся. Пример и пояснение видны в листе настроек.

## Покедекс: закрытые виды и экземпляры

Закрытая карточка показывает только номер, силуэт поддерживаемого вида и открытую подсказку местности. Поиск закрытых видов индексирует только номер/подсказку; скрытые имена, типы, редкость и описание не раскрываются через фильтры, порядок, tooltip или automation names. Фильтр скрытого свойства исключает закрытые записи, сортировка скрытого свойства выносит их в отдельную группу по номеру. Отсутствие ассета не открывает описание само по себе.

Видовое действие «Мои экземпляры» раскрывает список в той же карточке: кличка, уровень, shiny, занятость, дата поимки. Выбор открывает экземпляр по стабильному ID. При одном экземпляре допустим прямой переход; при нуле действие отсутствует. Оба пограничных состояния показаны в `index.html#states`.

UI использует международные English displayName из `../catalog-package/runtime-content.json`, русские авторские фактические обзоры и отдельные пользовательские клички. Покрытие 1025/1025, источники/ревизии включены. Это не перевод flavor text. Проверенных кириллических alias в снимке нет; автоматическая транслитерация не подменяет официальные имена.

## Служебные состояния

В финальном листе 18 состояний: закрытый вид с поиском по номеру/подсказке, выбор собственного экземпляра, нехватка ягод/монет, отставание команды, два участника без бонусов, недоступный вид, занятый родитель, бессмысленный талисман выбора, сохранённый результат, частично полезное зелье, однократный подарок, два подтверждения очистки, отмена похода, граница его завершения и подтверждение/защита передачи. Закрытие любого подтверждения ничего не списывает.

Производственная реализация: текстовые подписи вместе с цветом, клавиатурный фокус, озвучиваемые названия, видимые disabled-состояния с причиной, Esc для отмены, без автофокуса на разрушительном действии. Макетные disabled-кнопки и полноцветные статичные контролы — способ показать лист, не стандарт доступности приложения. Реальный компактный viewport и DPI проверяются в WPF.

## Решение 12 октября: только Chill (POKE-56)

Пользователь отменил Hardcore и SuperHardcore. Chill — единственный игровой режим: внимания и кормления достаточно для обычного ухода, настроение/реакции остаются мягкими, автоматического ухода со стола или постоянной потери экземпляра за невнимание нет. Выбор режима и SuperHardcore удаляются из настроек. Старые enum/поля допустимы исключительно для совместимого чтения: при загрузке/миграции/восстановлении нормализовать Chill/false, прежний штрафной `RanAwayUntilUtc` не ограничивает доступность. Не восстанавливать выдуманно экземпляры, уже переданные/потерянные в старом релизе; для этого доступна осознанная история восстановления. Остальные GUID, виды, shiny, XP/уход, даты, валюта и настройки сохраняются; исходный v1 и backups не меняются.

POKE-56 реализована и принята 12 октября: code `8e42790`, independent review Approved, full 592/592 (аппаратно-зависимый тест геймпада исключён). Защита сохранений POKE-55 также принята после двух fix/rereview; T04 сохраняет оба контракта. Предыдущие упоминания режимов/числа переключателей в макетах и исторических тестовых отчётах этим решением отменены; это не причина случая потери у друга, поскольку у него был Chill. T04 сохраняет восстановление и показывает только актуальные настройки, T18 не содержит наказаний, T20 проверяет совместимое чтение старых значений.
