# Передача фиксированного уголка в WPF

## Граница этой поставки

Готовы художественные данные, статичные затронутые экраны и согласованная логика. Защита текущих сохранений исправлена; глобальная схема и новые механики ещё не внедрены. Не переносить отвергнутые complete-room/next-zones как одобренную модульную систему. Финальные файлы — `art-production/last-attempt/final-assets/manifest.json` и `final/index.html`.

Существующие настройки, одиночное поглаживание/двойное открытие меню на рабочем столе, кольца прогресса, голос и общий игровой цикл сохраняются. Интерьер только внутри меню. Питомец остаётся самостоятельной анимацией, фон не содержит его или трофеев.

## 1. Сцена и данные

Загрузить114 PNG из final-assets. Фон1448×582. Размеры и точки опоры брать из манифеста, не из видимого центра. Для места с опорой (ax,ay) и изображения(w,h) позиция x=ax−w×footAnchor.x, y=ay−h×footAnchor.y. Три опоры: [664,280], [810,280], [956,280]. Затем наложить кромку [590,281,1031,288], последним — текущего питомца и согласованные эффекты реакций.

При Uniform-подгонке в область(W,H) использовать s=min(W/1448,H/582), одинаковый масштаб для всех комнатных слоёв и смещение ((W−1448s)/2,(H−582s)/2). Учесть реальную область изображения после letterbox, а не весь контейнер. Фон/фигурки сохраняют детализацию, пиксельная анимация питомца использует nearest. Пользовательские размеры питомца не сбрасывать.

Иви — только эталон регистрации:46×47, масштаб3, верхний левый угол[731,383]. Другие виды имеют свои прозрачные границы и габариты; проверить большие/малые виды, не назначать всем рамку Иви. Переиспользовать существующий GIF-декодер/кэш, не писать ещё один только ради комнаты.

## 2. Достижения

Канонических активных ID56:10 цепочек по4 и16 самостоятельных. Данные условий — ACHIEVEMENTS.md. population-N сохраняет ID и снова использует собственную растущую компанию Иви, без sourceId=decor-N.20 рисунков берутся из trophy-revision, остальные36 — из сохранённого исходного банка; в manifest.json указан точный источник каждой награды. Семь retiredIds из манифеста не выдавать.

Альбом26 карточек. У цепочки показывать только последнюю открытую версию; до первой — первую маску, не tier4. Маска белая с точной альфой, цвет силуэта задаётся UI-кистью. Закрытый трофей не выбирается на полку. После выдачи заполнить первое свободное место; заполненные не менять. Выставленная цепочка обновляет внешний вид без потери места. Выбор/снятие бесплатны, не являются достижением.

Счётчики привязать к подтверждённым игровым событиям и фактическим уникальным видам/экземплярам. Выдача и награды атомарны/однократны. Ретроспективно использовать только имеющиеся данные; отсутствующую историю не реконструировать предположениями. Условия «все» закрепить версией доступного каталога на момент получения. Не удалять существующие пользовательские данные, если при аудите обнаружатся старые/архивные ID; обработать их миграцией отдельно.

## 3. Меню и магазин

В уголке одна кнопка «Достижения» открывает альбом с блоком «Моя полка» сверху; отдельной кнопки «Полка» нет. Пять основных разделов и настройки остаются. У всех двенадцати товаров есть PNG-иконки из `assets/shop/manifest.json`, размер160×160; в обычной строке показывать80×80, в компактной64×64, равномерно без обрезки. Шесть ягод в одном прокручиваемом списке; положительное количество, общая стоимость и одна покупка. Вход из рецепта подставляет недостающее количество, покупка только по явному действию. Пачка лакомств/бустер ухода/shiny-талисман сохраняются; добавленные камень, талисман потомства и зелье опыта имеют принятую логику. Яйца и декор не продаются.

Отмена декора убрала расход монет; не повышать другие цены автоматически. Симуляцию темпа и экономики проводить отдельно с утверждёнными базовыми значениями. Обучение запускается после первого входа в крупное обновление и объясняет полку вместо покупки декора.

## 5. Приёмка реализации

- Обычное/компактное окно,150%/200%DPI, letterbox: все слои сохраняют опоры, текст не выходит за панели.
- Пустая/частичная/полная полка, заблокированные награды, новая ступень выставленной цепочки: без дублирования и авто-перезаписи полной полки.
- Перезапуск/старые данные/повторное событие: выбор сохранён, награда повторно не выдаётся.
- Большие/малые/shiny виды, исходные времена GIF, голос, существующая настройка масштаба и режимы ухода.
- Все шесть ягод доступны прокруткой, количество не требует множества кликов, нехватка монет/отмена не меняют данные частично, зелье у40 не расходуется.
- Обучение нового обновления однократно, возможность пропуска/повторного запуска, без обязательной траты ресурсов.

Эти проверки в приложении ещё не выполнены. Арт/данные проверены отдельными assert-скриптами и описаны в proof.json; они не заменяют приёмку WPF.
