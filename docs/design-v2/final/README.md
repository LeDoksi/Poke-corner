# Финальный дизайн-проект PokéCorner

**Главная сводка проекта: [GLOBAL-UPDATE.md](../../../GLOBAL-UPDATE.md).** Этот README описывает поставку final/; окончательные решения и карта всех материалов собраны в главной сводке.

Итог2026-10-11: рекомендуемый фиксированный интерьер со сменными заработанными трофеями. Большую модульную мебель дальше не развиваем. Это дизайн-поставка, не работающая новая версия приложения. Пользователь одобрил предложения смыслового аудита;24 исправленных внешних вида трофеев подготовлены и включены в экраны, новые картинки готовы к просмотру.

После пользовательской проверки: в уголке одна кнопка «Достижения», выбор трёх мест внутри альбома в блоке «Моя полка»; у всех12 товаров магазина появились отдельные прозрачные иконки. Источник/точный промпт/результаты технической нарезки: `assets/shop/`; генерация встроенным imagegen, техническая нарезка `prepare-shop-icons.py`. Аспир жёлтая, как в berry-profiles.json; прежняя подпись «голубая» исправлена.

[Аудит смысла трофеев и результат правок](TROPHY-SEMANTICS.md): исправлены все одобренные предложения —20 новых рисунков и4 возвращённые ступени компании Иви. [Новые трофеи](../art-production/last-attempt/trophy-revision/review.png), [точные промпты и нарезка](../art-production/last-attempt/trophy-revision/jobs.json). Генерация встроенным imagegen, только техническая нарезка/равномерный масштаб через Python. Канонические ID и условия достижений сохранены.

[Что остаётся в реализации](REMAINING.md): WPF, настоящие данные, миграционные фикстуры и проверки на устройстве. Подготовленные состояния, таблицы и схема миграции перечислены ниже.

[Статичные экраны](index.html): «Мой уголок», магазин расходников/всех шести ягод, альбом26 карточек с выбором3 мест полки, настройки, обучение и состояния действий. Без JavaScript и игровой интерактивности. Демонстрационные значения кошелька/коллекции подписаны вне макетов. Комната, трофеи, кромка полки и подлинный GIF питомца — отдельные слои.

Пакет для внедрения: [final-assets](../art-production/last-attempt/final-assets/README.md),114 PNG — пустой от наград фон, кромка,56 наград и56 белых opacity-масок; отдельно12 иконок магазина. Канонический манифест содержит sourceId, размеры и footAnchor.56 внешних видов =10 цепочек×4 ступени +16 самостоятельных целей, в альбоме26 карточек. Для роста коллекции возвращена компания Иви. Исторические63 исходника и87 декоративных вариантов не удалены.

Из магазина исключены декор/яйца; все расходники сохранены, ягоды доступны в одном списке с количеством. Удалены семь целей старого обустройства. Принятые цены, остальные пороги и игровые механики не менялись. Актуальные спецификации: [DECOR](../DECOR.md), [SHOP](../SHOP.md), [ACHIEVEMENTS](../ACHIEVEMENTS.md), [баланс](../BALANCE-REVIEW.md). Предыдущие версии трёх документов сохранены в `history/`.

[Передача в разработку](IMPLEMENTATION.md) задаёт границы, слои, миграцию и проверки. [Дизайн-система](DESIGN.md) описывает реально созданный пакет. [QA](QA.md) ограничена артом, данными и кодом статичных экранов; живое браузерное отображение/WPF не подтверждены. Политика инструмента не разрешает управлять локальной file://-страницей; её можно открыть вручную.

Проверено168 размещений наград, точное соответствие альфы56 масок, активные/архивные ID, все локальные ссылки и отсутствие JS. Все67 временных кадров Иви в эталонной APNG проверены; исходная анимация не перерисована. Полное поведение реальных сохранений, DPI и крупных/малых видов — этап внедрения.

Воспроизведение: `build.py` создаёт шесть статичных листов и checks.json; `../art-production/last-attempt/final-assets/export.py` создаёт пакет; `../art-production/last-attempt/assemble.py` создаёт растровые примеры/анимацию. После растровых генераторов выполнить provenance.py с корнем last-attempt для проверки метаданных. Python/Pillow — установленный bundled runtime, без новых зависимостей.
