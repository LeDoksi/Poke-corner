# Интерьерные ассеты PokéCorner

Актуальная завершённая поставка: [complete-room/README.md](complete-room/README.md), [полная галерея](complete-room/index.html), [канонический инвентарь](complete-room/inventory.json), [QA](complete-room/QA.md).

Полный ассортимент:87 вариантов декора и63 трофея. В `complete-room/assets/` отдельные канонические предметы, пустая база, четыре кромки полок и63 opacity-маски закрытых трофеев. Это готовая художественная поставка; внедрения в WPF нет.

Исходные каталожные атласы и ранний `previews/assembled-room.png` сохранены как история. Первый независимый PNG-коллаж был отклонён пользователем и готовым результатом не считается. `pilot-zones/` и `next-zones/` показывают принятый переход к общей сцене; некоторые контекстные источники этих этапов повторно использованы в полном пакете. Старый `production.py` воспроизводит исторические превью, новый полный пакет — `complete-room/build.py`.
