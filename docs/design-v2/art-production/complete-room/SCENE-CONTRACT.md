# Сценовый контракт полного интерьера

Визуальная власть: room-layout-v2.png / furniture-models-v1.png и принятый реальный зональный пилот. Общая камера неглубокая фронтальная, тёплый солнечный свет сверху слева. Кремовый фон, медовое дерево, шалфейные и приглушённые голубые акценты. Принятая разница манеры между подлинным BW-спрайтом и окружением сохраняется; питомца не перерисовывать.

Единица — один нативный пиксель. Комната 480×193; эталонный показ в 3 раза без сглаживания. Все предметы и фон масштабируются вместе, без независимой растяжки. `inventory.json` — источник размеров, координат, нормированных `footAnchor` малых объектов и `slotSizes`. У мебельных зон `position` указывает начало патча; их контекстные тени/контакты предназначены для этого места, свободное перетаскивание не вводится.

Порядок слоёв: стена/архитектура → ковёр → шторы → подоконное растение → картины → кресло → столик → шкаф → комод → трофеи → кромка полки → растения на столике/шкафу → напольное растение → лежанка → подлинный анимированный питомец. Подоконное растение находится позади кресла; трофеи позади собственного края полки. Лежанка сбоку, не связана со сном.

Опоры растений: подоконник `[88,94]`, шкаф `[307,73]`, пол `[23,172]`. Столики имеют разные опоры: T1 `[151,119]`, T2 `[151,116]`, T3 `[151,120]`, T4 `[151,116]`. На поверхностях допустимы только шесть малых видов; четыре напольных вида — только на полу. Размер для выбранного места брать из `slotSizes`, сохраняя пропорции. Купленный вариант повторно используется в подходящих местах без приобретения копий.

Центры картин `[221,41]`, `[266,41]`, `[311,41]`; их канонический холст 40×34. Опоры трофеев `[226,106]`, `[262,106]`, `[300,106]`; после постановки фигуры по `footAnchor` наложить `cabinet-cN-frontlip.png` в `[195,65]`. У четырёх шкафов общая геометрия логических мест, собственные кромки и материалы. Верхнее растение ставится независимо.

Силуэты закрытых наград: применять цвет интерфейса через белые RGBA opacity-маски `assets/locked/`. У цепочки показывается последняя открытая ступень, а до первого открытия — маска первой; будущие версии цепочки в продукте не раскрывать. Закрытые награды не выставлять на физическую полку. Первая награда занимает свободное место; заполненную полку не заменять автоматически, смена/снятие бесплатны, новая ступень выставленной цепочки обновляется на том же месте.

Для исходного BW Иви использован размер 46×47 и положение `[255,126]`, опора ног `[278,173]`. Его исходные RGB и временные кадры сохраняются. При внедрении других видов опору/габариты считать по их реальной прозрачной рамке; не делать все виды размером Иви и не запекать реакции в фон. Этот пакет содержит интерьер, а не новые покемонные анимации.

Стены — 12 самостоятельных базовых пластин до предметов; вне бумажных/оштукатуренных участков архитектура общая. Ковры содержат полную собственную форму, но в комнатном кадре передняя часть может продолжаться ниже края, как в принятом направлении. UI выбора показывает целый предмет и смысловое название; текст интерфейса в арт не запекать.

Проверены каждый предмет в комнате и ограниченная сеть мест/мебельных сочетаний. Внедрение должно отдельно проверить WPF-масштабирование, прозрачность/отсечение, работу с существующими сохранениями и производительность. Это оставшаяся реализация; художественная поставка завершена.
