# Полный интерьер PokéCorner — готовый арт-пакет

**Статус отменён пользовательской оценкой 2026-10-11.** Комод/лежанка, привязка штор, размер наград и попытка привести комнату к BW-сетке отклонены. Внутренняя QA `ship` ниже — историческая оценка, не приёмка владельца. Актуальная последняя попытка — [last-attempt](../last-attempt/README.md); эту библиотеку не внедрять как одобренную сцену.

Дата: 2026-10-11. Пользователь принял зональный пилот и поручил закончить весь ассортимент без промежуточных остановок. Полный интерьерный каталог собран; [независимая визуальная проверка](QA.md) завершилась `disposition: ship`, без существенных замечаний. Приёмка относится к арт-поставке, не к работающему WPF-приложению.

Смотреть [всю галерею](index.html), [заполненную комнату](previews/furnished.png), [альтернативное сочетание](previews/alternative.png), [старт](previews/starter.png), [промежуточный этап](previews/developing.png), [анимацию четырёх состояний](previews/room-tour.png).

Полный согласованный ассортимент: 150 предметных изображений — 87 вариантов декора и 63 внешних вида трофеев. Включены 16 конкретных моделей мебели, 6 лежанок, 20 растений, 12 картин, 12 ковров, 9 штор и 12 отделок стен. Все ID прежнего ассортимента сохранены. Для мебели используются контекстные состояния из принятого пилота и десять новых контекстных моделей; малый декор нормализован из сохранённых источников. Отвергнутый ранний коллаж не возвращён как готовая сцена.

`assets/` — канонические PNG всех 150 предметов для внедрения, пустая база и четыре кромки полок. `assets/locked/` — 63 технические маски силуэтов трофеев: альфа точно совпадает с открытым изображением, цвет задаёт интерфейс. `inventory.json` содержит пути, размеры, места и происхождение. Нативная сетка 480×193, эталонный показ 3× = 1440×579; [контракт сцены](SCENE-CONTRACT.md) задаёт порядок слоёв и точки опоры.

Проверено: точный набор 150 ID и файлов, 150 реальных превью предметов в заполненной комнате, 256 сочетаний четырёх категорий мебели, 80 проверок допустимых мест растений. Проверка трофеев включает 756 границ размещения и 84 полные сцены полок всех четырёх шкафов. В финальной анимации 268 исходных временных состояний питомца; непрозрачные пиксели BW Иви сохранены, все декодированные кадры совпадают с исходной сборкой. APNG: 252 закодированных кадра, 26,8 секунды, 1 295 495 байт.

Мебель и предметы независимы; растения располагаются в четырёх предусмотренных местах, картины занимают три места, трофеи — три места за передней кромкой полки. Лежанки пустые, сбоку. Стартовая сцена содержит только базовый столик/шкаф; остальной декор заполняется постепенно. Питомец не запечён в комнату.

Воспроизведение сборки: `build.py` создаёт канонические файлы, превью, галерею и assert-проверки. `surfaces/prepare.py` воспроизводит отделки/текстиль/пустую базу; `left-furniture/`, `right/`, `objects/` сохраняют источники, точные промпты, собственные генераторы и манифесты. После генераторов выполнить `provenance.py`: он нормализует читаемые метаданные PNG, не меняя декодированные пиксели. Python с Pillow доступен в bundled runtime, без новых зависимостей.

Границы: приложение и сохранения не менялись; WPF и браузерное воспроизведение не проверены. Полный набор всех возможных смешанных сочетаний декора не перебирался. Мелкие детали карт и фигурок ограничены нативной сеткой; выбирать их следует по смысловым названиям/увеличенному превью, а не по микроскопическим надписям внутри сцены.
