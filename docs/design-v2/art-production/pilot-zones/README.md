# Малый пилот зональной комнаты

Пользователь выбрал этот подход 2026-10-11 и принял показанный пилот: «ощущается, норм, давай, работаем». Это приёмка двух кресел с фиксированными столиком/растением и настоящим BW Иви; не автоматическое принятие всего интерьерного каталога. Следующая партия — независимые столики/растения и шкаф с трофеями в `../next-zones/`.

[Анимированная сборка](pilot-swap.png) автоматически чередует два кресла. [Статичная страница просмотра](index.html) показывает анимацию и оба состояния. [Состояние A](assembled-a.png) / [состояние B](assembled-b.png).

Общий `master.png` + реальные `zone-a.png` / `zone-b.png` + исходный `catalog-package/assets/normal/133.gif`. Столик и суккулент остаются фиксированными. Кресла нарисованы в окружении общей комнаты, а не независимо на прозрачном атласе. Питомец не запечён в фон и не перерисован.

Логическая сцена 480×193, показ при целочисленном масштабе 3. APNG: 126 закодированных кадров, 134 исходных временных состояния, 13,4 секунды, 529 664 байта. Все состояния декодированной анимации совпадают с технической сборкой; исходные непрозрачные пиксели Иви сохранены, вне зоны A/B совпадают. Проверки — `proof.json`; сборка и assert-проверки — `assemble.py`; происхождение — `derived-origin.txt` и точные промпты обоих состояний.

[Независимая визуальная проверка](QA.md): прежний жёсткий стык исправлен, мебель лучше связана с полом и светом. Разница контура/палитры между BW Иви и комнатой остаётся частично. Маска вручную подобрана только для этой пары; самостоятельная замена столика/растения, соседние зоны, трофеи и полностью заполненная комната не доказаны этим пилотом.

В приложение не подключено. Направление принято, производство продолжается проверяемыми партиями. Живое воспроизведение в WPF не проверялось.
