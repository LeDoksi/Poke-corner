# Комната с независимым декором — следующая партия

Продолжение принятого пользователем зонального пилота. [Анимация реальной сборки](room-independent-swaps.png) по очереди меняет один выбор: полку трофеев, шкаф, столик, растение, кресло. Настоящий BW Иви продолжает исходную анимацию; перерисованного питомца в фоне нет. [Статичная страница](index.html) без JS/игрового интерактива.

В партии:

- Два принятых кресла A1/A2.
- Два независимых столика T1/T2 с зарегистрированными точками поверхности.
- Суккулент/пилея либо пустая столешница.
- Два шкафа C1/C3 с пустой нишей, отдельным передним краем полки и тремя независимыми местами трофеев.
- Три существующих трофея как отдельные уменьшенные слои; к шкафу не запечены.

`compose.py` воспроизводит общую сборку и assert-проверки. `proof.json`: 48 сочетаний, неизменность общего мастера вне зон, сохранение левого уголка при замене шкафа, все 220 временных состояний APNG совпадают с сборкой и сохраняют исходные непрозрачные пиксели питомца. Анимация 22 секунды, 206 закодированных кадров, 948 044 байта. Она показывает 11 состояний, а не все 48 подряд; каждый переход, включая замыкание, меняет ровно один выбор.

`left/` содержит источники, маски, 12 сочетаний столиков/растений/кресел. `cabinet/` содержит два контекстных источника, зоны и кромки, опоры, манифест и проверку 378 границ (63 трофея × 3 места × 2 шкафа). Все 63 трофея визуально не утверждены; три примера не заменяют такую проверку. Полный масштаб ограничен этой партией; другие растения, столики и шкафы требуют собственной регистрации контакта.

[Общая визуальная проверка](QA.md), [шкаф](cabinet/QA.md). В одном корректирующем проходе очищен подтверждённый остаток столешницы на альфе пилеи и замкнута последовательность смены предметов. Независимое подтверждение повторно проверило все 220 временных состояний и 11 переходов; открытых замечаний этой проверки нет. В приложение не подключено. Следующие ещё не произведённые в этом новом методе узлы: правый комод/боковая лежанка, окно/шторы/подоконник, настенные картины, пол/ковры, остальные модели и полное заполнение комнаты.
