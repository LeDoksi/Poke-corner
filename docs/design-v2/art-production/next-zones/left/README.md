# Независимые столики и растения

Продолжение принятого зонального пилота. В этой партии два кресла A1/A2, два столика T1/T2 и суккулент/пилея/пустая столешница: 12 реальных сборок. Кресла берутся из принятого пилота; новый столик и растение нарисованы в окружении той же комнаты.

Просмотр: [автоматическая смена отдельных предметов](independent-swaps.png), [все 12 сочетаний](all-12-combinations.png). В этой демонстрации Иви показан первым исходным кадром; его настоящая анимация остаётся в предыдущем `pilot-zones/pilot-swap.png`.

Артефакты: `master-no-plant.png`, две зоны столиков, две прозрачные маски растений, отдельные источники contextual edit, точные промпты. `assemble.py` восстанавливает сборки и проверяет 12 случаев, сохранение исходных непрозрачных пикселей Иви, неизменность сцены вне левого уголка и независимость растений от остальных предметов. Растения получают альфу по фактической разнице с зарегистрированной пустой столешницей; RGB взят из исходного изображения, без перерисовки.

У двух столиков разные точки поверхности: `[151,119]` и `[151,116]` на сетке 480×193. Горшок привязывается основанием к выбранной поверхности. Для других моделей требуется собственная регистрация контакта и маски. Исходный мастер комнаты сохраняется; случайные изменения окна/архитектуры из генераций в итог не переносятся.

Визуальный просмотр матрицы: расположение и размер мебели согласованы с принятым пилотом, смена отдельного предмета читается. Полная комната, соседний шкаф и край ковра проверяются в общей сборке следующего блока. В приложение не подключено.
