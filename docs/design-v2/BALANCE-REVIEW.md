## 2. Базовая добыча экспедиций

Рекомендуемые уровни лёгкой/обычной/сложной: 1/10/25. Базовая монетная добыча 6/8/12 в час. Ягодная база лёгкой и обычной одинакова, сложной x1,5. Малые дробные количества требуют отдельной проверки округления, минимум основной ягоды сохраняется.

Бонус среднего уровня +0,25% за уровень выше 1 (до +9,75%). Каждый подходящий по типу участник +3% к базовой добыче. Отставание от рекомендованного: −2,5% за уровень, максимум −50%, затем множитель состава 0,8 для одного. Бонусы ресурсов вместе с особенностями ограничить +40%. Опыт не снижается штрафами добычи. Точные комбинации проверить: неподготовленная сложная команда не должна всегда выигрывать у подходящего маршрута.

Подходящие типы, предложение: роща Grass/Bug/Poison; озеро Water/Normal; побережье Water/Flying/Fairy; горы Rock/Fighting/Dragon; пустыня Ground/Dark; вулкан Fire/Steel; снег Ice/Normal; руины Ghost/Psychic/Electric. Это игровые бонусы, не канонические правила.

## 3. Встречи и дополнительные находки

Встреча максимум одна за поход. Базовый шанс при нормальной подготовке: p=1−(1−q)^h, где h выбранные часы, q лёгкая 3%, обычная 5%, сложная 7%. Для обычной длительности примерно 2,5/7,4/14,3/26,5%. Это исходные числа для обсуждения.

Веса редкостей встречи: лёгкая 75/22/2,8/0,2, обычная 60/30/9/1, сложная 45/35/17/3. Внутри категории одинаковый вес допустимых видов, затем особенности изменяют соответствующие веса. Гарант новизны активности не переносится на экспедиции. Новые виды из питомника/экспедиций не сбрасывают флаг последнего дубля активности; доступный неизвестный пул обновляется всегда.

Дополнительная находка: одна проверка за каждые выбранные 30 минут; базовый шанс 10/20/30% по сложности. Успешная обычная находка — дополнительная ягода или монеты, рабочая пропорция 60/40. Предметы отдельно открывает Искатель реликвий; распределение камень/талисман гнезда/shiny-талисман 60/30/10. Числа и шанс редкой находки должны учитывать силу команды относительно рекомендации. Повторные открытия результата не перебрасывают находки.

## 5. Особенности — принятые значения I/II/III

- Собиратель: +5/10/15% ягод базы.
- Кладоискатель: +5/10/15% монет базы.
- Следопыт: +10/15/20% к вычисленному конечному шансу встречи p, относительное увеличение; предел 95%, почасовой q не меняет.
- Искатель: +10/15/20% к шансу дополнительной находки, относительное.
- Наставник: +5/10/15% опыта всем участникам.
- Коллекционер: вес неизвестного вида x2/x3/x4 внутри выбранной категории экспедиционной встречи. Это не постоянный процент новизны.
- Искатель реликвий: 1/2/3% на отдельную предметную находку за каждые выбранные 30 минут.
- Знаток местности: −5/8/12% времени экспедиции.
- Быстрорастущий: −5/10/15% требования накопленного ухода; ягодную цену не меняет.
- Знаток редкостей: веса Rare/Legendary x1,1/x1,2/x1,3, затем нормализация.
- Заботливый родитель: −5/8/12% времени гнезда.

Дубликаты эффектов: сильнейший 100%, второй 50%, третий 25%; порядок слотов не влияет. Общий предел сокращения времени 25% для экспедиций, 20% для гнёзд. Ускорение активностью принято: каждые 500 действий во время похода дают −1% выбранного времени, максимум −10% при 5000; входит в общий предел 25%. Награды считаются по выбранной длительности, не ускоренному времени.

Случайная вторая особенность и переобучение равномерны среди допустимых незанятых вариантов. Быстрорастущего исключать из новых назначений и наследования ребёнку без дальнейшей эволюции. Если допустимых уникальных родительских особенностей не осталось, выбрать случайную допустимую из общего списка; варианты/шансы видны до запуска (принято). Уже имеющуюся особенность не менять при эволюции автоматически.

## 6. Питомник: время, шансы, рецепты

Последнее уточнение: потомство только начальный вид полной цепочки, включая baby-виды; готовые эволюции из яйца запрещены. Одинаковые родители тоже дают начальный вид своей семьи. Талисман не обходит это правило. Покрытие каталога считать через «вылупление + эволюции», легендарные рецепты — по начальным видам семей.

Время по наиболее редкому возможному виду пары: Common 2ч, Uncommon 4ч, Rare 6ч, Legendary 8ч. Выбор с талисманом не меняет время. После запуска свойства родителей не пересчитывают уже зафиксированный результат. Эта шкала заменяет 1,5/3/6/12: обычные и необычные рецепты стали немного дольше, легендарные короче.

Принятые веса результатов Common/Uncommon/Rare/Legendary 8/4/2/0,5 нормализуются по конкретным 2–3 вариантам. Пользователь подтвердил разные проценты легендарных результатов; единые 5% отклонены. Недоступные результаты исключаются из действующего расчёта. Для одинаковой редкости равные шансы. Талисман гарантирует выбранный доступный начальный вид.

Последнее согласование времени: 2/4/6/8 часов определяются максимальной редкостью ДОСТУПНЫХ результатов. Если легенда пока заблокирована ассетами, она не повышает время остальных исходов. При запуске время фиксируется, обновление каталога не меняет действующее гнездо.

Рецептная сеть построена черновиком: NURSERY-RECIPES.md. Все 541 начальный вид имеют рецепт; полный каталог 1025 покрыт через вылупление и эволюции. В текущем BW-каталоге 13 цепочечных результатов блокируются отсутствующими ассетами звеньев; не выдавать готовую эволюцию из яйца как обход. Количество разных пар для остальных редкостей подбирается по каталогу, не фиксировать произвольный лимит. Неподготовленные normal-начальные виды видны как недоступные; исключаются ДО запуска, шансы остальных нормализуются. Недоступный shiny не исключает обычный исход. Если нет доступного результата, запуск недоступен; если остался один, не продавать выбор талисманом без смысла.

## 7. Shiny

Накопительная удача действует ТОЛЬКО в питомнике; пригодное обычное яйцо увеличивает её, shiny-яйцо сбрасывает. При технически невозможном shiny удача остаётся прежней. Поимки за активность и экспедиции не используют, не увеличивают и не сбрасывают бонус питомника. Общий shiny-талисман может применяться к любому прежнему источнику; x4 умножает именно его актуальный шанс. Это закрывает вопрос области действия удачи.

Предложено сохранить текущую базу 1/512 (~0,195%) для встреч и начала питомника. Обычное вылупление +0,25 процентного пункта общей удачи, потолок итогового шанса без талисмана 10%; shiny сбрасывает накопленный бонус. Талисман умножает текущий шанс x4, тратится при любом результате попытки. Родительский shiny не влияет.

Старый скрытый x4 бонус дублям в CatchRoller убрать, оставив понятные базу/удачу/предмет. При отсутствии пригодного shiny у выбранного фактического вида шанс 0%, талисман остаётся активным и накопление питомника не меняется. При обычном исходе реальной пригодной попытки предмет расходуется.
