# Реакции v1 — приёмка Claude (04.11)

Исходный пакет Астры лежит на ПК Georgy: `PokeTokenBar-Windows\docs\design-v2\reactions-v1` (не в репозитории).
В приложение попали листы из `src/PokeCorner.App/Assets/Reactions/`:

- `clean.py` — убирает полупрозрачную грязь: альфа только 0/255, пятна меньше 2 px удаляются, палитра сводится к 14 цветам (кормление — 32, чтобы сердечко не стало коричневым).
- `neglect3.py` — перерисовка третьей обиды поверх облачка Астры: вместо кораллового крестика лицо «ну всё, я обиделся» — брови к центру, зажмуренные глаза, надутые губы; кадры 13–14 — смягчившееся лицо при внимании.
- Тайминги и порядок кадров — из `manifest-astra.json`, перенесены в `ReactionPlayer.cs`.
- Хруст — кандидат Астры `feeding-crunch-v2.wav` (два укуса, второй на 180 мс), стартует на кадре 5.

Запуск: `python3 clean.py <out>` с листами Астры в `/mnt/user-data/uploads/reactions-v1/assets/` (путь поправить под себя).
