# Настройки — проект экрана

Общие эффекты следуют системной настройке анимаций Windows (`SystemParameters.ClientAreaAnimation`): при отключении клубок остаётся постоянным неподвижным значком. Отдельного переключателя движения в PokéCorner нет.

Инвентаризация 2026-10-05: SettingsView.xaml и AppSettings.cs. Ни одна текущая видимая настройка не удаляется. Это статичный дизайн, настройки приложения не изменялись.

## Существующие возможности

- Chill по умолчанию: без последствий пропущенного ухода. Hardcore: при невнимании питомец уходит со стола на час. Супер Хардкор: вместо временного ухода навсегда покидает коллекцию. Последний выключен и недоступен в Chill; последствия явно подписаны, без смягчающих эвфемизмов.
- Скрывать питомца в полноэкранных приложениях: включено по умолчанию.
- Показывать прогресс рядом с питомцем: выключено по умолчанию. Три кольца: поимка, уход до эволюции, получение лакомства.
- Размер питомца 48–384 px, исходно 96; применяется сразу.
- Громкость голоса питомца 0–100%, исходно 70%; 0 — тишина, голос при поглаживании. Переименование «крика» в «голос» не означает, что новые голосовые ассеты уже получены.
- Громкость эффектов (`EffectsSoundVolume`) 0–100%, исходно 30%; 0 отключает crunch и другие общие эффекты, сохраняя независимый голос. Для миграции отсутствующее поле получает 30. Crunch: `voice-preview/audio/feeding-crunch.wav`, оригинальный процедурный звук; источник и SHA — `voice-preview/delivery.json`.
- Автозапуск при входе в Windows, исходно выключен.
- Показать обучение.
- Обучение обновляется под новый набор функций. По требованию пользователя автоматически запускается при первом входе в обновлённое приложение, в том числе для существующих пользователей, ранее завершивших обучение. Кнопка в настройках позволяет пройти его повторно. Подробности — ONBOARDING.md.
- Очистить сохранённые данные: коллекция, прогресс, настройки; затем перезапуск. Сохранить существующее двойное подтверждение; макет не выполняет это действие.
- Информационный блок об активности мыши/клавиатуры/геймпада: считается количество нажатий, не содержимое. Это пояснение, не переключатель. Не возвращать удалённый учёт токенов.

В модели дополнительно есть монитор, угол размещения и координаты перетаскивания. В SettingsView.xaml для них нет контролов; не выдавать их за существующие элементы настроек. При миграции сохранять значения.

## Предложение нового экрана

Один раздел настроек, группы «Питомец на рабочем столе», «Режим ухода», «Звук и движение», «Система», справка об активности. Две колонки на широком окне, единая вертикальная прокрутка на узком. Без отдельных страниц на каждый переключатель. Обычные изменения применяются сразу, отдельная кнопка «Сохранить» не нужна.

Отключённые системные анимации Windows сокращают бросок, покачивание, вспышки и переходы до спокойного короткого подтверждения, не скрывая результат. Базовые анимированные спрайты сохраняются. Состояние показывается в настройках поясняющим текстом и меняется вместе с Windows, без нового переключателя. Отдельные громкости музыки и окружения не добавлять до проектирования этих звуков.

Краткая памятка: клик — погладить; двойной клик — открыть меню. По умолчанию питомец остаётся без окружающих индикаторов.

Правила и состав настроек зафиксированы; текущий лист — `final/index.html`. Наличие Hardcore и его обычные последствия сохраняются из приложения.
