# Пользовательский просмотр POKE-57 — 17 октября 2026

Экраны без комментариев приняты. Исправляем один связный пакет до переноса в WPF; не объявлять полное визуальное одобрение. Проверить каждый пункт по фактическому управлению/виду, не только присутствию текста.

- F01: настоящая нарисованная монета во всех местах; знак отмены исключён.
- F02: применение бустера ухода и зелья опыта к выбранному питомцу, запас/эффект/действие видимы.
- F03: уголок — убрать бессмысленное «Всё хорошо», явно назвать уход для эволюции, питомец крупнее на30%, имя/номер/типы и прочая краткая идентичность.
- F04: «Мои» — без массового «Свободен», редкость на карточке, «Есть куда расти», «Дубли», избранные, shiny, тип и редкость; фильтр «Готовы к эволюции» исключён. Дубли определяются по виду независимо от клички и shiny.
- F05: «Все виды» — нет индивидуальной занятости, экземпляры раскрываются отдельно; развитые виды не выдаются за прямые встречи в роще. Фильтры без утечки закрытых свойств. Нет плашки или отдельного фильтра «Есть в коллекции»; визуально открытые виды не требуют дублирующего фильтра «Открытые виды».
- F06: личная карточка — явная шкала эволюции, подготовленное фактическое описание, кнопка эволюции возле цепи, на стол возле имени, действие «Найти новый дом».
- F07: отдельное состояние разветвлённой эволюции с выбором камнем/случайно, цена и доступные/закрытые ветки.
- F08: участник похода — одновременно особенность и соответствие маршруту. Не выбирать одну из двух полезных подписей.
- F09: подготовка питомника — выбор другого родителя настоящими кнопками.
- F10: ожидание питомника — цельная иллюстрация с яйцом внутри, без PNG-наклейки; нет выбора родителей после запуска.
- F11: готовое яйцо — крупная цельная сцена с трещинами и одно локальное действие «Вылупить».
- F12: альбом — прогресс/следующая ступень трофея; настоящее управление3местами полки.
- F13: закрытый покебол — явная активация талисмана удачи со статусом и запасом.
- F14: поимка — показать бросок, покачивания, открытие; отдельный сценарий встречи уже открытого покемона из экспедиции.
- F15: все подтверждения — overlay поверх текущего контекста, без нового пустого экрана; отмена/Esc/возврат фокуса.

Новые17окт рисунки цельного ожидания, крупного треснутого яйца и монеты пользователь уже одобрил. Точные промпты — revision2-prompts.json, после копирования находятся в наборе ui-system. Фоны/PNG не включаются в runtime до этапа переноса. Математика и проценты остаются под капотом; точные предметы/цены/время показываются. Неназванные принятые экраны не перерабатываем.
