# Поимка — варианты постановки

Поиск выполнен17окт2026. Пользователь выбрал полную поимку с Pokémon. Она собрана в наших макетах, в приложение ещё не включена. Ссылки — примеры для просмотра, не подтверждение их визуальной приёмки пользователем.

1. [Pokeball Catch Animation — jocchann](https://codepen.io/jocchann/pen/MyxedP): бросок к видимому Pokémon, исчезновение при захвате, три покачивания, искры и результат. Рекомендовано взять постановку за основу и оформить нашими принятыми пиксельными ресурсами; не переносить чужой GIF/стиль страницы. Последовательность переносится в WPF, сайт/библиотеки не нужны в приложении.
2. [CSS Animated Poké Ball — raubaca](https://codepen.io/raubaca/pen/obaZmG): падение с небольшим отскоком и три покачивания. Более сдержанный ориентир; полноценного взаимодействия с питомцем нет.

[LottieFiles Pokeball — Justin](https://lottiefiles.com/free-animation/pokeball-7gc1qsv2Mz) —1.8KB, вращение/лоадер. Не рекомендуется как полноценная поимка.

Поиск не установил наличие готового официального файла с разрешением на встраивание. [Pokémon Support](https://support.pokemon.com/hc/en-us/articles/360000634094-Can-I-use-Pok%C3%A9mon-images-or-materials) не предоставляет такого разрешения. Не выдавать доступный в интернете официальный GIF за разрешённый ресурс. [Правила CodePen](https://blog.codepen.io/documentation/licensing/) относят код публичных примеров кMIT; это не подтверждение прав на сторонние Pokémon-изображения внутри примера. Здесь чужой код/ассеты не копировались.

Предложенный сценарий для PokéCorner: известный Pokémon остаётся на месте встречи, покебол летит к нему, короткая вспышка и втягивание, приземление с отскоком, три покачивания с паузами, щелчок/искры и результат. Для неизвестного покебола не повторять вопрос во время движения. Снижение движения Windows сокращает переход, результат остаётся понятным. У новой постановки одна итоговая приёмка в составе связного UI.

Текущая поставка: [LATEST-REVIEW.md](LATEST-REVIEW.md), capture.js/css. Это авторская реализация последовательности своими ресурсами; новые35состояний и полная анимация ожидают визуальной оценки.
