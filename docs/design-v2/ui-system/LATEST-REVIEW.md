## Команда экспедиции и подсказка получения

Первый поход начинается с трёх пустых мест; отправка недоступна до выбора хотя бы одного питомца. «Выбрать команду» и «Изменить команду» открывают один целый экран. Три места закреплены сверху, каталог прокручивается внутри, «Готово» и счётчик всегда доступны. Выбор черновой: «Отмена» оставляет прежний состав, «Готово» применяет от1до3экземпляров; четвёртый недоступен. Обычный/shiny одного вида выбираются отдельно. Спутник рабочего стола и занятые питомцы недоступны с понятной причиной.

Демонстрационная коллекция800экземпляров: поиск по имени/кличке/номеру, тип, особенность (основная или вторая), «Доступные» по умолчанию и «Подходят маршруту». Сортировки: рекомендованные (доступность, тип маршрута, рекомендуемый уровень, высокий уровень), высокий уровень, номер.12экземпляров на странице; сброс фильтров сохраняет выбранных. При смене маршрута/сложности подсказка и рекомендации обновляются. Особенности и совпадение с маршрутом видны отдельно. Вторая особенность соблюдает secondTraitLevel=10 из balance.json. Ожидаемая добыча в макете иллюстративная; реальные расчёты подключаются при переносе.

«Где найти?» у закрытого базового вида — отдельная native кнопка на второй строке с10pxотступом. Открывает прежнюю подсказку маршрута/пар питомника; развитые формы не предлагаются для прямой ловли.
