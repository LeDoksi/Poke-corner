## Что изменено

- Нарисованная монета; питомец уголка крупнее на 30%, видны имя/номер/тип/редкость/уровень; шкала названа «Уход для эволюции».
- В «Моих» редкость и фильтры «Есть куда расти», «Дубли», избранные, shiny, тип, редкость, поиск и сортировка. «Готовы к эволюции» отсутствует. Дубли — несколько экземпляров одного вида независимо от клички/shiny.
- Во «Всех видах» нет индивидуальной занятости, плашки/фильтра «Есть в коллекции» или его замены «Открытые виды». Неоткрытые свойства не находятся поиском; развитые виды отмечены эволюцией из предыдущей формы. Свои экземпляры раскрываются отдельно.
- В личной карточке восстановлен подготовленный обзор вида, действия сгруппированы у имени/эволюции, есть «Найти новый дом» и применение бустера/зелья к выбранному питомцу с подтверждением.
- Новые сценарии: эволюция Eevee случайно/камнем с восемью ветвями, анимированный бросок/покачивания/открытие, экспедиционная встреча знакомого вида.
- У участников похода одновременно видны особенность и соответствие роще. Родители выбираются настоящими кнопками. Ожидание и готовность питомника — цельные сцены с яйцом внутри; готовность крупным планом и с одним локальным действием «Вылупить».
- Альбом показывает текущий прогресс/следующий этап; полка управляется тремя местами. Талисман явно активируется и расходуется в демонстрации поимки.
- Подтверждения отображаются поверх своего текущего экрана; начальный фокус на отмене, есть Esc и ограничение фокуса в диалоге.

Nunito, кремовые поверхности, лесной зелёный, общий SVG-набор и реальные GIF/PNG сохранены. Игровых процентов/шансов/коэффициентов нет; точные цены, количества, уровни и время остаются. Новые рисунки делаются по индивидуальным композиционным промптам.

## Проверка и границы

Одна начальная проверка, один связный пакет исправлений и итоговое подтверждение: **64 сочетания, 32 состояния × 2 размера** (1000×760 и 840×650). Нет горизонтального переполнения, битых видимых изображений и игровой математики в тексте. Длинные каталоги прокручиваются. Ключевые изменённые композиции просмотрены по снимкам; отдельный визуальный PASS всех 64 сочетаний не заявляется.

Проверены: дубли Росток/Клевер, shiny Pikachu, отсутствие поиска закрытого Ivysaur, два предметных подтверждения с именем питомца, восемь ветвей/выбор #0134 с 6 Oran и камнем, смена родителя, трофей на полке, активация талисмана, покачивания и переход к результату; три подтверждения с сохранённым контекстом/отменой/Esc. Синтаксис JS и все локальные ссылки проверены. [Матрица](proof/revision2/confirmation-matrix.json), [взаимодействия](proof/revision2/interactions-final.json), [снимки](snapshots/revision2/).

Начальные доказательства сохранены отдельно; старый тест ready в interactions-initial.json описывает снятый фильтр и не является текущим контрактом. Итоговый контракт — interactions-final.json. Предметные/трофейные действия проверяют сценарии макета, а не реальные игровые сервисы. Не проверялись WPF, DPI Windows, миграция настоящего профиля или MSI.

Четыре первоначальных рисунка приняты 16 октября: [provenance](art-provenance.json). Ещё три рисунка приняты 17 октября: цельное ожидание, крупный план треснутого яйца, прозрачная золотая монета; [источники, хеши и индивидуальные промпты](revision2-art-provenance.json). Отдельное яйцо сохранено как ранее принятый ресурс, но не накладывается на сцены ожидания/готовности. Новые PNG не зарегистрированы в runtime.

Из корня репозитория: `rtk proxy python docs/design-v2/ui-system/build.py` при доступном Python/Pillow. build.py использует revision2.py, общие review.css/review.js и revision2.css/revision2.js. Все исходные изображения локальны; внешние CODEX_HOME-пути для пересборки не требуются. PNG копируются byte-for-byte. Четыре остальных маршрута автоматически не заменялись: [направления](../ART-DIRECTION.md).

## Следующий этап после оценки

1. Зафиксировать замечания только к изменённым экранам и согласовать пакет.
2. Перенести общую оболочку, токены, кнопки/поля/карточки/предметы/шкалы и overlay в WPF.
3. Переносить целые связанные сценарии: уголок + покедекс/карточка/эволюция; затем походы + питомник; затем магазин/альбом/поимка/настройки/копии/знакомство.
4. Подключить существующие игровые сервисы без изменения Chill, выдачи корневых видов и защиты сохранений. Проверять функциональные изменения по мере подключения; косметику собрать в один общий проход.
5. Одна итоговая визуальная проверка по принятым макетам, один пакет исправлений и подтверждение. Затем POKE-34/T20: DPI/рабочая область, реальные копии профиля, offline publish и обновление MSI с сохранением прогресса.

POKE-57 ожидает пользовательской оценки исправленного пакета; POKE-34 остаётся зависимой. Эта последовательность — предложение для согласования, разрешением на перенос не является.
