За ступени цепочек5 /10 /20 /40 монет. Самостоятельные выплаты — отдельный параметр реализации, не назначать40 автоматически всем. Каждая цель даёт свой физический трофей; его нельзя купить, он не повышает добычу.

Только открытые награды допускаются к размещению. Одна кнопка «Достижения» внутри «Моего уголка» открывает альбом; управление размещением находится сверху этого же экрана в блоке «Моя полка».
