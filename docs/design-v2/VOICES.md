# Голоса — переносимая поставка 2026-10-11

## Канонический ресурсный пакет

`voice-preview/audio/` содержит все 868 выбранных WAV: 717 itch, 127 Pixelmon, 24 согласованных временных cries.latest PokéAPI. Обычный и shiny-экземпляр используют один звук вида. `voice-preview/delivery.json` — единый SpeciesId → относительный path → SHA-256 → PCM-формат; также содержит исходный URL/member/SHA и признак temporary. Все файлы декодированы в PCM16 WAV 44 100 Hz (1–2 канала), без изменения темпа или нормализации громкости. Для 24 cries URL получен через исходный `https://pokeapi.co/api/v2/pokemon/{id}/`, затем скачан именно `cries.latest` из официального PokeAPI/cries. 868/868 готовы, pending-fetch=0.

Архив itch в Downloads использован только при подготовке после проверки SHA. В runtime и офлайн-проверке Downloads, исходный RAR, OGG, FFmpeg и сеть не нужны: поставляются перечисленные WAV и manifest. Оригинальные архивы и прежние превью сохранены. Проверка: `rtk proxy python -X utf8 docs/design-v2/voice-preview/prepare-delivery.py --check`; исходная подготовка — тот же скрипт с `--archive <approved-rar>`, повтор получения только недостающих согласованных cries — `--fetch-pending`. Отчёт `delivery-checks.json`: 868 голосовых файлов, 1 эффект, 159 221 260 байт, SHA/PCM проверены.

Crunch — отдельный `audio/feeding-crunch.wav`, 0,18 секунды оригинального процедурного тихого шума, без чужих аудиосэмплов. Его генератор, SHA/формат и происхождение находятся в том же manifest. Громкость эффектов отдельно: 0–100%, default 30; голос 0–100%, default 70.

Подготовка не означает подключение к WPF или индивидуальное прослушивание 868 записей. Использование выбрано для личного круга пользователя; права публичного перераспространения источников не подтверждались. Запасной Cobblemon не подставляется в основной набор.
