# PokéCorner — прототип v1

Кликабельный дизайн-проект для обсуждения, отдельно от WPF-приложения.

Запуск из корня репозитория:

```powershell
rtk proxy node docs/prototype-v1/server.cjs 4181
```

Открыть http://127.0.0.1:4181/docs/prototype-v1/ . Сервер слушает только localhost.

Пройдите уголок → экспедиции → питомник → коллекцию → магазин. Альбом достижений открывается из уголка. Покупка растения меняет комнату, выбранные значки появляются на полочке.

«Завершить ожидание» демонстрирует возвращение экспедиции и появление яйца. «Сбросить демо» возвращает исходное состояние. Данные хранятся только в localStorage браузера; сохранения приложения не затрагиваются.

Цены, длительности, награды и пороги — примеры для обсуждения. Настоящий офлайн-таймер, вероятность встреч, полный каталог, аниме-голоса и баланс не реализованы. Показанные анимации взяты из существующих ресурсов проекта.
