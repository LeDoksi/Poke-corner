## Общие требования к растру

- Ночная пиксельная живопись с авторскими кластерами, глубина в 3 плана. Камера внутри места, без открыточного дальнего вида.
- Никакого текста, кнопок, покемонов и трофеев в картинке.
- Сцена маршрута: ширина ≥ 2400 px, соотношение около 3:1, важное держится в центральной полосе, потому что края обрезаются при окне 1200×660 и раскрываются при развёрнутом.
- Хранить исходник, точный промпт, дату и хеш; в сборку попадает только экспорт.

## Приёмка каждой картинки

- [ ] Место узнаётся без подписи; на общем листе восьми сцен нет повторяющейся композиции (центральная дорожка, арка, деревья по краям)
- [ ] Выполнены запреты брифа (роща без воды, вулкан вплотную, руины без сада)
- [ ] Кроп проверен при 1200×660 и при развёрнутом окне
- [ ] Заголовок места и текст поверх сцены читаются
- [ ] Палитра совместима с токенами Night Diary
- [ ] Записаны исходник, промпт и хеш

Если картинка не прошла приёмку, Claude описывает конкретные проблемы и готовит исправленный промпт.
