Тесты App на ПК Georgy: 715 из 726, 11 старых визуальных тестов v2 падают (так же было до Night Diary).

## Приоритеты

**Обязательно для релиза**
- Безопасные миграция и upgrade (этап 2).
- Все экраны в одной теме Night Diary, без остатков v2.
- Сцены всех 8 маршрутов и ночная комната.
- Баги POKE-73 (склонение «монет»), POKE-74 (абзац в питомнике), POKE-75 (счётчик встреч).
- Зелёный набор тестов: визуальные тесты v2 переписаны под новую тему.
- Актуальный README.

**Существенные улучшения**
- Богатые поля на всех основных экранах.
- Короткие пути по примеру экспедиций: проверить результат питомника и поимку на лишние шаги.
- Перерисованные иконки монет, ухода и лакомств.
- Клавиатурный фокус и читаемость на всех экранах.

**Полировка (если останется время, иначе после релиза)**
- Арт для событий (вылупление, эволюция).
- Анимации переходов.
- Windows CI в GitHub Actions.
- POKE-28, POKE-30, POKE-31.
