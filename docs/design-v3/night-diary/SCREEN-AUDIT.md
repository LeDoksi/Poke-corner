# Аудит связности экранов

Статус: проход 1 по коду, 28.10.2026, ветка `codex/night-diary-pilot` на 0b33a8e. Мерило — [COMPONENTS.md](COMPONENTS.md), разделы 2 «Компоновка кнопок» и 3 «Выходы и навигация». Проход 2 будет по живым скриншотам 1200×660 и FullHD после того, как тред раскраски зальёт свои изменения: часть пунктов ниже про цвет и стиль может закрыться там.

Важность: **А** — тупик или потеря действия, **Б** — лишний шаг или путаница, **В** — несогласованность.

## Карта переходов (как сейчас)

```
Рейка: Уголок ─ Покедекс ─ Экспедиции ─ Питомник ─ Магазин        Настройки (низ рейки) ⇄ «К разделам»
Шапка: «Встречи · N» → Уголок/Поимка

Уголок/Питомец ─ «Достижения» → Альбом ─ «Назад в уголок»
               ─ «Карточка питомца» → Покедекс + страница питомца
Уголок/Поимка  ─ «Бросить» → анимация (пропуск) → результат ─ «Продолжить» → снова Поимка
Покедекс/Мои   ─ плитка → страница питомца ─ ✕/Esc
                 страница ─ «Условия» → эволюция ─ «← К питомцу» и «Позже» (одно и то же)
                          ─ «В магазин» → Магазин (нехватка выбрана)   ─ «В поход» → Экспедиции
                          ─ «Найти новый дом» → подтверждение
Покедекс/Все виды ─ плитка → страница вида ─ «Встретить: маршрут» → Экспедиции; «Питомник: A+B» → Питомник
Экспедиции ─ «Выбрать команду» → подбор ─ «Отмена»/«Готово»
           ─ «Отправить» → поход ─ «Прервать» → подтверждение «Оставить/Прервать»
           ─ «Забрать находки и открыть встречу» → Уголок/Поимка
Питомник  ─ «Выбрать» → подбор пары ─ «Отмена»/«Сохранить пару»
          ─ «Начать ожидание» → ожидание ─ «Вернуться в уголок»
          ─ «Вылупить» → анимация ─ «Продолжить» → результат ─ «Карточка малыша» / «На рабочий стол» / «Новое гнездо»
          ─ «Докупить ягоды» → Магазин (нехватка выбрана)
Магазин   ─ «Выбрать питомца» → Покедекс (выбор питомца для предмета); «К поимке» → Поимка
```

Тупиков в строгом смысле нет: рейка видна везде, кроме оверлея подтверждения. Но есть места, где после действия человек оказывается не там, откуда пришёл, и обратной дороги кроме рейки нет.

## Что проверено и в порядке

- Подтверждения: опасное — «Оставить / Прервать», Esc = выход, клик по затемнению не закрывает, фокус возвращается на место (тест есть).
- Настройки: «К разделам» и Esc возвращают в прежний раздел.
- Альбом: «Назад в уголок».
- Экспедиции: один клик от возвращения до встречи (D-02), отмена с подтверждением, пустая команда разрешена до старта с объяснением.
- Покедекс: страница вида ведёт в экспедиции и питомник с готовым контекстом (D-19).
- Тур: «Позже» на каждом шаге, «Назад» со второго.

## Что ещё не проверено

- Живые скриншоты всех состояний на 1200×660 и FullHD (проход 2).
- Трей, питомец на рабочем столе, кольца прогресса, окно истории сохранений, выбор стартера — по коду выходы есть, вид не смотрел.
- 800 питомцев в подборах после смены подписей пагинации.
