# Инвентаризация интерфейса — этап R1 / POKE-70

21 октября 2026. Статический проход по исходникам новой версии + техническая сверка субагентом Sol. База f958a145c4e82136ffc1cd18a02bafb560e3de19, дерево global-update. Все пути ниже относительны корню этого дерева.

**37 исходных ID сопоставлены с реализацией. Дополнительно выделены 11 семейств состояний/поверхностей. Это не утверждение, что требуется 48 отдельных экранов.** Полнота относится к указанному индексу и найденным текущим точкам входа. Поведение описано по коду и существующим определениям тестов; приложение в этом проходе не запускалось.

Машинная карта: [inventory.json](inventory.json). План и зависимости: [PLAN.md](PLAN.md).

## Навигация и реальные границы

AppMenuWindow.Navigate: пять основных разделов — уголок, покедекс, экспедиции, питомник, магазин. Достижения и поимка сейчас вложены в уголок; настройки открываются отдельно с возвратом в прежний раздел. Оболочка содержит валюту/встречи, hosted content (тур/история) и overlay-подтверждения.

Это функциональная структура, не обязательная прежняя компоновка. Боковая навигация нового эскиза и набор миниатюр маршрутов подлежат проверке R2/R3. Компонентный лист components — стенд дизайна/QA, не пользовательский раздел.

Входы вне оболочки: первый запуск со стартером, startup recovery, desktop pet/progress, трей и сообщения Windows. Их нельзя потерять при замене темы главного меню.

## Сквозная матрица состояний

| Условие | Что должен видеть пользователь | Что проверять |
|---|---|---|
| Пустой список/поиск/команда/родители | Объяснение и действие выхода/сброса/выбора | Не показывать ошибку вместо нормального empty |
| Недоступный экземпляр/ресурс/действие | Причина рядом с выбором, читаемый disabled | Причина сохраняется при смене темы; не только цвет |
| Выбор и редактирование | Текущий выбор, черновик, применить/отмена, клавиатурный фокус | Отмена не меняет сохранённое; закрытие не применяет случайно |
| Ожидание commit | Блокировка повторного действия и понятное ожидание | Не публиковать tentative state; не тратить второй раз |
| Отказ записи | Понятный результат отказа и доступный безопасный retry | Та же операция; прежние данные/запасы; ошибки не исчезают при перерисовке |
| Уход/возврат/закрытие при await | Актуальное состояние после возврата | Поздний callback не меняет другую карточку/скрытый экран |
| Успех/готовность | Один результат, следующий понятный шаг | Claim/Hatch/reveal однократны; награда не теряется |
| Длинный текст | Читаемый перенос, прокрутка подробностей, доступное действие | Кличка, факт, способности, цена и опасное подтверждение не перекрываются |
| Арт отсутствует/повреждён | Честная заглушка и доступ к данным | Не менять вид/shiny, не скрывать экземпляр |
| Отключено движение | Тот же сценарий и результат с меньшим движением | Windows setting; нет обязательного длинного reveal |
| Малое окно/DPI | Действия достижимы, контент прокручивается | Нет горизонтального overflow и обрезанного подтверждения |

## Данные и неизменяемые функции

- Покедекс: 1025 видов информационно; выдача отдельно по доступности варианта BW. Мои экземпляры и открытые виды — разные сущности. Фильтры, дубли, normal/shiny, избранное, номер/имя/кличка, даты, характер и способности сохраняются.
- Личная карточка: имя с явным редактором и отменой, переобучение самостоятельным действием, предметы ухода с реальными иконками, факты офлайн. Эволюция сохраняет экземпляр и семейные правила; камень выбирает точную цель.
- Экспедиции: 8 маршрутов, easy/normal/hard, 30/90/180/360 минут; 1–3 участника. Сцена/награды следуют настоящему preview. Пустой выбор разрешён до старта, перегружать команду нельзя. Одновременно один поход; ready/result/encounter и подтверждение раннего возврата отдельны.
- Питомник: два разных точных экземпляра, совместимость и занятость, талисман, preview/ягоды/время/нехватка. После старта исход заморожен, до Hatch/reveal скрыт. Новая выдача — root, включая baby; сохранённые развитые родители допустимы по прежним правилам.
- Магазин: 12 товаров, из них 6 ягод; количество, итог, запас, контекст нехватки, подтверждение. Предметы применяются к выбранному экземпляру; repeated successful purchases получают разные операции.
- Поимка: закрытые активностные/подарочные покеболы и известная экспедиционная встреча различаются. Талисман, очередь, пропуск/уменьшение движения, закрытие/возврат используют committed результат.
- Уголок/альбом: уход, активный экземпляр, комната и трофеи отдельными слоями, полка на 3 места. Декор не переносится на свободного питомца рабочего стола.
- Настройки: только Chill; fullscreen hiding, progress panel, размер, громкости голоса/эффектов, autostart, повтор тура, история, двойной reset. Приватность счётчика активности не теряется в новом тексте.
- GUID, валюты, XP, инвентарь, открытия, история, retry и commit-before-publish сохраняются. UI-редизайн не меняет продуктивные данные.

## Фикстуры для последующих этапов

Явный перечень фильтров для сохранения функций:

- Экспедиции: поиск, тип, особенность, доступность, соответствие маршруту; сортировки рекомендации/высокий уровень/номер. Фильтра редкости в этом подборе сейчас нет (ExpeditionView.xaml:80–86).
- Питомник: поиск, редкость, Shiny (NurseryView.xaml:140–142), далее группа вида и точный экземпляр.
- Коллекция: редкость, тип, готовность эволюции, дубли, избранное, Shiny; поиск и сортировка. Каталог видов имеет собственные тип/редкость/сортировку (CollectionView.xaml:207–215,270–281).
- Тур: «Назад» доступен со второго шага, на первом отключён; «Пропустить» доступно и на последнем. Завершение ведёт в уголок, не бросает подарочный покебол автоматически.
